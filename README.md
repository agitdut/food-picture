# Steam, Noodles, Lift

Entry for make.fun's `food-picture-01` bounty ($250, program/v1): the
best-looking food picture.

The picture: a steaming bowl of tonkotsu ramen — chopsticks lifting a
tangle of glossy noodles, chashu, a halved egg with a jammy orange
yolk, scallions, steam curling up in soft window light. Shot close,
so the first thing you want to do is eat it.

The program (`main.ts`) copies `entry.png` to `/output/entry.png`.
The file is a PNG under 1 MiB, 1024 px tall, within the gate's limits.
